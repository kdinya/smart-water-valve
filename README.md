# Water Valve Card v3.1.0

Lovelace-картка з формою вибору ентіті. Без інтеграції.

## Поля форми

- **Кран** (обовʼязково) — switch / valve  
- **Датчик протічки 1** (опційно)  
- **Датчик протічки 2** (опційно)  
- Сенсор стану / батарея — опційно  

Якщо датчик не вибрано — його блок **не відображається**.  
Один датчик → один блок. Два → два блоки.

У шаблоні за замовчуванням **немає жодного entity_id**.
