Smart Water Valve (Fixed)

Ця версія дозволяє створювати пристрій у Home Assistant з вибором:
- ентіті крана (switch/valve)
- ентіті датчиків протєчки (binary_sensor)

Використання
1. Скопіюйте файли у папку customcomponents/smartwater_valve.
2. Перезапустіть Home Assistant.
3. У меню Налаштування → Пристрої та служби додайте новий пристрій.
4. Виберіть ентіті крана та датчики протєчки.
