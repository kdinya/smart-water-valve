# Water Valve Card v4.0.1

## Install

**HACS → Frontend → Lovelace**

Repository: `https://github.com/kdinya/smart-water-valve`

1. Download 4.0.1  
2. **Ctrl+F5**  
3. F12 console → must see `WATER-VALVE-CARD` / `4.0.1`  
4. Add card → search **Water Valve** or **Водяний**

If the card is missing from the picker: the JS is not loading. Check **Settings → Dashboards → Resources** for `water-valve-card.js` (type: JavaScript Module).

Remove old `/local/water-valve-card.js` if present.
